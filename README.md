| `항공기기체정비 기능사 영상 시험 문제.pptx` | 조종면 · 3축 운동 · 지상장비 · 공구 · 측정기구 |
| `파이프 배관 작업.pptx` · `파이프 길이 계산.xlsx` | 배관 길이 계산식과 정답표 |

**선택형 문항의 정답은 자료의 답 그대로**이고, 나머지 보기는 같은 항의 다른 문항의 답에서
골랐습니다. 지어낸 보기는 하나도 없습니다. 발문을 되풀이하거나 정답과 겹치는 보기,
발문 안에 정답이 그대로 들어 있는 문항은 걸러 냈습니다.

### 자료 쪽 오류 하나

`파이프 배관 작업.pptx` 의 **수행평가 1번 전체길이**가 **407.7** 로 적혀 있는데,
같은 표의 구간 값을 그대로 더하면 **417.7** 입니다(10 차이). 이 도구는 식으로 계산한
417.7 을 정답으로 봅니다. 배우기 화면에도 그렇게 적어 두었습니다.

### 자료 쪽 오류 둘

`항공기체정비기능사+구술시험.hwp` **204번**이 미터식 버니어 캘리퍼스의 최소 측정값을
「1/20(**0.005 mm**), 또는 1/50(**0.002 mm**)」 라고 적고 있으나, **1/20 mm = 0.05 mm**,
**1/50 mm = 0.02 mm** 입니다(0 이 하나 더 붙었습니다). 같은 자료의 계산 보기
(4.5 + **0.22** = 4.72 mm)도 0.02 mm 눈금이라야 나오는 값입니다.
버니어 게임은 **0.05 · 0.02 mm** 로 만들었고, 문답 카드에는 자료 문장을 그대로 두고
배우기에 바로잡는 설명을 따로 붙였습니다.

### 못 넣은 것

`2022학년도 2학년 항공드론과 1학기 기말고사.hwp` 는 **문서 암호가 걸려 있어 열지 못했습니다.**
암호를 알면 문항을 더 넣을 수 있습니다.

## 잠금

자료가 국가기술자격 공개문제 기반이라 **파일 자체를 AES-GCM 으로 암호화**해 올립니다
(`bank.enc`). 정적 호스팅에서는 화면에 비밀번호 칸만 두면 파일 주소를 직접 쳐서
받아갈 수 있기 때문입니다. 암호는 도구 공용이고, 한 기기에서 한 번 열면 나머지 도구도 열립니다.

```powershell
python build_lock.py          # content.js(평문) -> bank.enc
```

`content.js` 는 `.gitignore` 에 있습니다. **커밋하지 마세요.**
고쳤으면 반드시 `build_lock.py` 를 다시 돌려야 배포본에 반영됩니다.
